# Welcome to loop. 👋

You’re on the loop. team: Beatriz (lead), Noor, Bianca, Ferdinand, Marcelo, Dalya, Ghaya.
loop. turns your course material into a 5-minute swipeable revision feed. Try it: https://studywithloop.github.io/app/

## 1. Get access (5 min)
1. Make a free GitHub account if you don’t have one: https://github.com/signup
2. Send your GitHub username to Beatriz. She’ll invite you to the **Studywithloop** organisation.
3. Accept the invite email from GitHub.

## 2. Find your tasks
- Open https://github.com/Studywithloop/loop-app/issues
- Click the **label with your name** to see your tasks. Assign yourself when you start one.
- Roles and owners: `docs/TEAM.md`. Pitch plan: `docs/PITCH.md`.

## 3. Work with Claude Code (recommended, even if you don’t code)
Claude Code reads `CLAUDE.md` in this repo, so everyone’s Claude starts with the same context: product, brand, rules, who owns what.
1. Install Claude Code (desktop app or terminal): https://claude.com/claude-code
2. Get the repo on your laptop. Ask Claude Code: *“clone github.com/Studywithloop/loop-app and open it”*, or run `gh repo clone Studywithloop/loop-app`.
3. Open the `loop-app` folder in Claude Code and ask things like:
   - “What’s my task? I’m Bianca.”
   - “Help me build the competition slide with sources.”
   - “Make a branch, update docs/PITCH.md with my numbers, and open a pull request.”

**Not technical?** You can do everything in the browser too: open a file on GitHub, click the ✏️ pencil to edit, and press **Commit changes**.

## 4. Team rules
- Never put real student emails, phone numbers or grades in the repo or in Claude.
- Passwords and API keys go in `.env`, never in a file you commit.
- Small changes, one pull request each, and one teammate reviews before merging.
- Stuck for more than 30 minutes? Comment on your issue and tag Beatriz.

Cool kids stay in the loop. 💜
