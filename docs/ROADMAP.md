# Roadmap: MVP → final product

## Where we are (MVP, live)
- Demo feed (Edtech Challenge: business models) with quizzes and “swipe to reinforce”
- Video clipping into equal 90-s clips with recall pauses
- Make-your-own feed via copy-paste into ChatGPT/Claude
- Sign-ups and in-app feedback → Google Sheet; branded welcome email

## Phase 1 — learn (this week)
- Summarise class feedback; 30 interviews; 48-hour recall experiment (Dalya)
- 2–3 professors interested in a pilot (Bianca)

## Phase 2 — make it real (2–4 weeks)
- **Video clipper** (Noor, Ferdinand): clips cut by topic from the transcript + a question per clip
- **Generator** (Beatriz): upload a PDF/slide deck in the app → feed built automatically, no copy-paste
- Small backend to call the Claude API safely (API key never in the browser)

## Phase 3 — pilot (next term)
- One course, one professor: approve feed, class dashboard of most-missed concepts
- Accounts (sign in), saved progress, spaced repetition up to the exam date
- Permissions: professor consent for material; IE IT for login and GDPR

## Phase 4 — scale
- Installable web app (PWA) + notifications → native app once retention is proven
- Track AARRR: activation (first feed finished), week-2 retention, referral (shares to class)
